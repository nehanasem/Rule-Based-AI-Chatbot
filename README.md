# 🤖 NOVA — Rule-Based AI Chatbot

**A simple, interactive rule-based chatbot built with Python**

## 📌 About the Project

NOVA is a beginner-friendly chatbot that interacts with users through predefined responses and keyword-based matching. It uses Python programming concepts to simulate a basic conversational experience.

The project demonstrates how a simple AI-style chatbot can respond to different user inputs using rules and conditions rather than machine learning.

## ✨ Features

- **Interactive conversation:** Communicates with users through the terminal.
- **Intent recognition:** Identifies common topics using keyword matching.
- **Predefined responses:** Provides responses for different conversation categories.
- **Dynamic replies:** Selects varied responses to make conversations more engaging.
- **Input handling:** Converts input to lowercase and handles extra spaces and punctuation.
- **Fallback responses:** Responds when it doesn't recognize the user's message.
- **Exit commands:** Allows users to end the conversation easily.

## 🛠️ Technologies Used

- Python 3
- `random` module
- `re` (Regular Expressions)

## 🚀 How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python chatbot.py
```

5. Start chatting with NOVA!

## 💬 Example Conversation

```text
NOVA: Hello! I'm NOVA, your friendly chatbot.
You: hello
NOVA: Hey there! Great to see you!

You: I like burgers
NOVA: Burgers sound delicious!

You: thank you
NOVA: You're very welcome!

You: exit
NOVA: Goodbye! Have a wonderful day!
```

*Example responses may vary because NOVA selects some replies randomly.*
